# OrchestraAI v1.0 — User & Conductor Guide

Welcome to **OrchestraAI** — the multi-agent AI coding studio designed to conduct entire teams of autonomous AI developers.

---

## 1. Quick Start

### 1.1 Creating a Workspace
1. Launch OrchestraAI.
2. On the Welcome Hub, click **"Open Project Folder"** (or press `⌘O` / `Ctrl+O`).
3. Select an **Agent Team Preset** (e.g. *Feature Factory*, *Bug Hunt*, or *Full Stack*), or configure custom terminal panes.
4. Toggle **"Isolate features in git worktrees"** if you want each agent to develop in independent branches.
5. Click **"Launch Workspace"**.

---

## 2. Navigating the Workspace

### 2.1 Workspace Tabs & Split Terminals
- **Top Tab Strip**: Compact tabs show active workspaces, folder icons, and pane count badges. Double-click any tab to rename it.
- **Split Terminals**: Drag and drop pane headers to rearrange terminals side-by-side or stacked vertically.
- **Broadcast Mode (`⇧⌘B` / `Ctrl+Shift+B`)**: Send keyboard input simultaneously to all focused agent terminals.

### 2.2 The Right Panel (Explorer, Git & Orchestra Pit)
The Right Panel opens automatically on the right side with 3 primary modes:
- **Files (Explorer)**: Browse the project folder hierarchy, filter files, and double-click to open files directly in your preferred editor (VS Code, Cursor, Zed, Sublime, IntelliJ).
- **Git Inspector**: View uncommitted changes, inspect colored inline diffs, check the commit history timeline, and list branches.
- **Orchestra Pit**: The central room where all AI agents communicate, share contracts, coordinate progress, and receive directives from you.
